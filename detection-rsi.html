1. 统一模板与三个开关

能收成一个模板。这十一个数据集做的是同一件事：一张图进去，一组带类别的框出来，分数按同一套办法计算。

① 输入输出有共性

图像进，带类别的框出。XML、JSON、文本、比例坐标只是文件写法，进模板前转成同一份框。

② 核心指标有共性

按重叠配对，按类算平均精度，再对类取平均。可选最差类 AP。mAP@0.5 与 mAP@[0.5:0.95] 来自同一次评测。

③ 只留三个开关

框是水平的还是四个角点；重叠只取 0.5，还是从 0.5 取到 0.95 再平均；要不要额外报召回率。各数据集仍报自己那一档。

水平框数据集报矩形重叠。DOTA 报旋转框重叠。Anti-UAV 在同一套配对上再读 Recall。对不上的类按 0 分留在平均里，不从类别里删掉。

3. 数据集细节

点一下切换。数字来自已经接上的官方划分，类别个数不另编。

20 类 mAP@0.5 框是 XML 里的左上角和右下角。airplane 对照成 aeroplane 这类同一种东西的不同拼法。

选择用 2012 trainval：200 张筛选，800 张确认。报分用 2007 test，4952 张，只评一次。选定 n0096，0.8413，基线 0.8282。

80 类 mAP@[0.5:0.95] JSON，框是左上角加宽高，进模板时换成右下角。类别名与冻结检测器一致。

选择用 val2017 里的 200 / 800 张。报分用完整 val2017，5000 张。测试集标注不公开。选定 n0036，0.3852，基线 0.3688。同一版的 mAP@0.5 是 0.6049，基线 0.5847。

10 类 mAP@[0.5:0.95] 文本行，左上角加宽高。人对照到行人，摩托车对照到 motor。人群、厢式车、三轮车不改名。

在官方 val 上筛选，最多 3 轮。报分用 test-dev，1610 张。选定 n0005，0.0408，基线 0.0327。

旋转框 文本里八个数，四个角点。飞机对照到 plane，船对照到 ship。评测用旋转框重叠 0.5。

大图按 1024 切块，框再拼回原图坐标。筛选 40 张，确认 120 张。报分用官方 val 全部 593 张，测试集标注不公开。选定 n0006，0.0156，基线 0.0106。

mAP@0.5 表格里的框是相对宽高的比例。成组标注不当成一个物体。手机对照到 mobile phone，鼠标对照到 computer mouse。

任务表写 V7。服务器上评的是能下载到的 v5 验证集，34413 张。v6 标注返回 403。筛选 200，确认 600。选定 n0004 与基线四舍五入后都是 0.0458。

365 类 mAP@[0.5:0.95] JSON，左上角加宽高。只对照同一种东西的别名，例如餐桌、电视。

筛选 200，确认 600。报分用官方 val，80000 张。选定 n0005，0.0514，基线 0.0492。

221 种标志 mAP@0.5 JSON，左上角和右下角。标志代码不改成检测器里的类名。

官方 test 上能对照上的类别是 0，所以用公共基线，分数是 0。对不上的类按 0 分留在平均里。

无人机 mAP@0.5 与 Recall 每一帧有没有目标，以及左上角加宽高。飞机不改叫无人机。

可见光 test 用公共基线。mAP@0.5 和 Recall 都是 0。

TinyPerson、BDD100K、Cityscapes 已经挂在同一份契约上，状态是等数据。图片还没到，所以没有分数。骑行者不改叫人。

4. RSI 搜索环

seed n0000→ parents ≤ 3→ 每个孩子只改一处→ 筛选→ 确认→ Pareto→ 官方划分评一次

筛选

小子集先看苗头。按该数据集的主指标排序，留下 2 个进入确认子集。

Pareto

同时看主指标和最差类 AP。两项都不差、并且至少一项更好，才算压过另一个版本。留下的父节点最多 3 个。

版本树

每个节点一份 encoder.py 和 decoder.py，记下父节点和这一处改动。VOC 的树在 versions_logic/n0096。

默认搜索超参

项默认含义
max parents × children3 × 2每轮最多 6 个新版本。每个版本只改一处
进入确认的个数2筛选后只把前 2 名放到更大的子集上再算
VOC 筛选 / 确认200 / 800取自 2012 trainval。报分用另一套 2007 test
VOC、COCO 轮数最多 20，连续 8 轮无提升停止COCO 在子集搜索进行中，用当时最好的 n0036 做了完整 val2017
VisDrone、DOTA、OpenImages、Objects365最多 3 轮，连续 2 轮无提升停止DOTA 筛选 40、确认 120。OpenImages 与 Objects365 是 200 / 600
大脑Faster R-CNN 冻结权重不可训练。果蝇连接组不承担这次检测，也不被改写

一轮里，每个父节点尽量生出两个孩子：一个改处理步骤，一个改常数，并且尽量一个落在 encoder、一个落在 decoder。祖先用过的改动不再提。官方划分不参与挑选，只在最后和基线各评一次。

实际留下的版本：VOC n0096，COCO n0036，VisDrone n0005，DOTA n0006，OpenImages n0004，Objects365 n0005。TT100K 与 Anti-UAV 用公共基线。

6. 代码布局与怎么跑

rsi-system/rsi_system/
  contracts.py      # 目标检测这一份契约
  adapters.py       # 十一个数据集的文件和类别对照
  catalog.py        # 各数据集选定的 encoder / decoder
  detection.py      # 覆盖范围和本页
  system.py         # 给出任务和数据集，返回 encoder / decoder
  execute.py        # 决定能不能跑

voc-rsi/
  encoder.py        # 图像进检测器之前
  decoder.py        # 框出来之后
  propose.py        # 每个父节点最多两个孩子，各改一处
  search.py         # 筛选、确认、Pareto、官方评测一次
  evaluate.py       # 冻结 Faster R-CNN，算 mAP@0.5
  tree.py           # 版本树
  versions_logic/n0096/   # VOC 选定版本

常用命令

cd /home/zhaozhenhao/rsi-system
python3 -m rsi_system cover
python3 -m rsi_system prepare object_detection voc

# VOC 的搜索循环在
# /data1/zhaozhenhao/voc-rsi/search.py
# 解释器用
# /data1/zhaozhenhao/venv/sku110k_torch/bin/python

这样做的好处：每一处涨分都能对上版本树上的一个改动；检测器不训练；挑选用子集，官方划分只评一次；主指标和最差类一起留；新数据集只加适配器。
